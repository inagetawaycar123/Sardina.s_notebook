美丽的递推
```c
int Partition(int *array, int low, int high){
    int pivot = array[low];
    while(low < high){
        while(high > low && array[high] >= pivot){
            --high;
        }
        array[low] = array[high];
        while(low < high && array[low] <= pivot){
            ++low;
        }
        array[high] = array[low];
    }
    array[low] = pivot;
    return low;
}
  
extern void QuickSort(int *array, int low, int high){
    if(low < high){
        int pivotpos = Partition(array, low, high);
        QuickSort(array, low, pivotpos-1);
        QuickSort(array, pivotpos+1, high);
    }
}
```

这个的代码实现好简单
- 首先写一个分割函数，以最左边的数为基准，双指针遍历，从两边到中间。
	- 从右边开始走，遇到小于基准数的数，令`low`指针的数等于该数，然后`low`指针运动。
	- 你会非常神奇的发现，虽然没有用`temp`，但是数据也没有丢失，只有最开始`low`指针指向的数存储在了`pivot`中，这个数最终被赋给`low`与`high`相遇的位置
- 接着是`Quick Sort`主体，更神奇啊，先判断`low`与`high`有没有相遇，然后对分割线左边用一次，右边用一次递归，短短几行就实现了
