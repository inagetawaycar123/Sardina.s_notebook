```c
extern void ShellSort(int *array, int length){
    int gap, i, j, temp;
    for(gap = length/2; gap > 0; gap /= 2){
        for(i = 0; i + gap < length; i++){
            j = i + gap;
            if(array[i] > array[j]){
                temp = array[i];
                array[i] = array[j];
                array[j] = temp;
            }
        }
    }
}
```
超级简单的排序
间隔gap排序，gap不断缩小，好用的，冒泡排序的升级版
